# DevMind Platform

Plataforma integral de herramientas CLI para desarrollo de inteligencia artificial sobre Linux.

## Instalacion

```bash
pip install -e .
```

## Comandos

| Comando | Descripcion |
|---------|-------------|
| `devmind` | Muestra la ayuda general |
| `devmind doctor` | Diagnostica el sistema completo (GPU, Docker, Ollama, RAM, etc.) |
| `devmind gpu` | Verifica GPUs, drivers CUDA y Vulkan |
| `devmind init` | Inicializa un proyecto de IA con estructura estandar |

## Requisitos

- Linux (Ubuntu 20.04+, Fedora 38+, Arch Linux)
- Python 3.11+
- Opcional: NVIDIA GPU + drivers, Docker, Ollama
